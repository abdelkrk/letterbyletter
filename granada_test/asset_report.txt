IMPORTANT NOTE — WHY FILES AREN'T IN THIS REPO
This coding environment's network egress policy blocks direct connections to the
Higgsfield CDN domain (confirmed earlier when testing Frame 001 and the TTS sample).
The sandbox_exec tool runs in a completely separate remote sandbox with its own
internet access, so it can reach the CDN — but that sandbox's filesystem is
ephemeral (discarded shortly after each call, though it persists across
back-to-back calls in the same session) and is not connected to this repository's
filesystem. There is no available mechanism in this session to transfer 103MB of
binary image data from that remote sandbox into this git-tracked directory.
